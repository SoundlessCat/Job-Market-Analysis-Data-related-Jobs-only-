# Data Jobs Market Analysis – Power BI

Interactive Power BI dashboard analyzing 630 survey respondents
across job roles, salaries, programming languages, demographics,
and workplace satisfaction.

## Key Analysis

- Average salary by data-related job role
- Programming language preferences
- Country distribution
- Gender composition
- Education level
- Workplace satisfaction
- Job-market trends

## Tools Used

- Power BI
- DAX
- Power Query
- Data Cleaning
- Data Visualization
